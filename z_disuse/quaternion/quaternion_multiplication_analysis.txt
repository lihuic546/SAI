Quaternion Multiplication Analysis
==================================

クォータニオンの掛け算公式:
q1 * q2 = (w1*w2 - x1*x2 - y1*y2 - z1*z2,
           w1*x2 + x1*w2 + y1*z2 - z1*y2,
           w1*y2 - x1*z2 + y1*w2 + z1*x2,
           w1*z2 + x1*y2 - y1*x2 + z1*w2)

あなたのコードの計算:
===================

Q1 = Q2 = (0.707, 0, 0, -0.707)  // Z軸まわり -90°
Q3 = Q5 = (0.707, -0.707, 0, 0)  // X軸まわり -90°
Q4 = (0.707, 0, 0, 0.707)        // Z軸まわり +90°

計算1: Q1 * Q2 = (0.707, 0, 0, -0.707) * (0.707, 0, 0, -0.707)
w = 0.707*0.707 - 0*0 - 0*0 - (-0.707)*(-0.707) = 0.5 - 0.5 = 0
x = 0.707*0 + 0*0.707 + 0*(-0.707) - (-0.707)*0 = 0
y = 0.707*0 - 0*(-0.707) + 0*0.707 + (-0.707)*0 = 0
z = 0.707*(-0.707) + 0*0 - 0*0 + (-0.707)*0.707 = -0.5 - 0.5 = -1

結果: (0, 0, 0, -1) = Z軸まわり -180°

計算2: Q4 * Q3 = (0.707, 0, 0, 0.707) * (0.707, -0.707, 0, 0)
w = 0.707*0.707 - 0*(-0.707) - 0*0 - 0.707*0 = 0.5
x = 0.707*(-0.707) + 0*0.707 + 0*0 - 0.707*0 = -0.5
y = 0.707*0 - 0*0 + 0*0.707 + 0.707*(-0.707) = -0.5
z = 0.707*0 + 0*0 - 0*(-0.707) + 0.707*0.707 = 0.5

結果: (0.5, -0.5, -0.5, 0.5)

回転の合成の意味:
================

1. Q1 * Q2 (Z軸-90° * Z軸-90°) = Z軸-180°
   - 同じ軸まわりの回転は角度が加算される
   - -90° + (-90°) = -180°

2. Q4 * Q3 (Z軸+90° * X軸-90°)
   - 異なる軸の回転の合成
   - 最初にX軸まわり-90°、次にZ軸まわり+90°の複合回転

クォータニオン掛け算の特徴:
========================

1. 非可換: q1 * q2 ≠ q2 * q1 (一般的に)
2. 結合法則: (q1 * q2) * q3 = q1 * (q2 * q3)
3. 回転の合成: q2 * q1 は「まずq1の回転、次にq2の回転」を意味
4. 単位クォータニオン同士の掛け算も単位クォータニオン

実用的な意味:
============

- クォータニオンの掛け算は回転の合成を表現
- 複数の回転を順番に適用する場合に使用
- ロボティクスや3Dグラフィックスで姿勢制御に重要
